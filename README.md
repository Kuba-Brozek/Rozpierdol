# Rozpierdol

Prosta apka webowa (PWA) do śledzenia wagi i treningów. Działa offline i instaluje się na iPhonie przez Safari → „Dodaj do ekranu początkowego”.

- **Dieta**: pomiary wagi, BMI, postęp do celu, wykres, import i kopia w Excelu
- **Trening**: dziennik serii, plany treningowe, podpowiedzi z poprzedniego razu
- **Ćwiczenia**: 873 ćwiczenia ze zdjęciami, ulubione, własne ćwiczenia
- **Chmura**: opcjonalna synchronizacja przez Firebase (każde konto widzi tylko swoje dane)

Dane użytkowników nie są przechowywane w tym repozytorium. Są tylko w telefonie i, po zalogowaniu, w Firebase.

Opisy i zdjęcia ćwiczeń pochodzą z [Free Exercise DB](https://github.com/yuhonas/free-exercise-db) (Unlicense, domena publiczna). Zdjęcia są pomniejszone do 480 px.
